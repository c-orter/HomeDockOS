## <img src="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/icons/numbers.png" width="30" align="top" alt=""> HomeDock OS in Numbers

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/stats-dark.png">
    <img alt="800+ self-hosted apps, 80+ file types in the browser, 0 plugins to install, 3 operating systems, free forever" src="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/stats-light.png" width="100%">
  </picture>
</p>

- **800+ apps** — 180+ curated in the official App Store, plus community stores one click away.
- **80+ file types** — Photos, camera RAWs, PSDs, spreadsheets, CSVs, Word documents, PowerPoint presentations, PDFs, code, music and video, right in the browser.
- **Zero plugins** — No office suite, no codecs, no image editor to install. It all ships inside HomeDock OS.
- **3 OSes, 4 architectures** — Linux, macOS and Windows, on x86, x86_64, ARM and ARM64. Yes, even a Raspberry Pi Zero.
- **1 certificate** — A single automatic Let's Encrypt wildcard covers every app you install, without opening a port for it.
- **€0, forever** — The full desktop, free. No trial, no account, no strings attached.

## <img src="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/icons/open.png" width="30" align="top" alt=""> Built in the Open

The pieces HomeDock OS is made of are becoming standalone open-source projects, one by one, under real OSI-approved licenses (open source, totally true this time). HomeDock OS itself stays source-visible for now, and our [CONTRIBUTING](https://github.com/BansheeTech/HomeDockOS/blob/main/CONTRIBUTING.md) explains why and when that changes. The same code that runs your desktop, published so anyone can use it, audit it and build on it:

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/open-source-dark.png">
    <img alt="Prism Window Manager (@prism-wm, AGPL-3.0), the windowing system for Vue 3, React and Svelte; and vite-fusion (MIT), the bridge between Flask and Vite with HMR, CSP nonces and React Fast Refresh" src="https://raw.githubusercontent.com/BansheeTech/Logo/refs/heads/main/homedock-os/readme/open-source-light.png" width="100%">
  </picture>
</p>

- **[Prism Window Manager](https://github.com/BansheeTech/prism-wm)** (`@prism-wm`, AGPL-3.0): the window manager behind every HomeDock OS window. A framework-agnostic core with bindings for **Vue 3**, **React** and **Svelte**: dragging, resizing, snapping, dialogs, and memory management for minimized windows.
- **[vite-fusion](https://github.com/BansheeTech/vite_fusion)** (`pip install vite-fusion`, MIT): serves a Vite frontend from Flask, with the dev server and hot reload while you work, the production manifest when you ship, CSP nonces on every tag and React Fast Refresh.

We needed both to build HomeDock OS, so we built them as standalone packages and gave them back to the community: free, open source and published on PyPI and npm.
